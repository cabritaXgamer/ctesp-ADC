Gestor de Campanhas
===================

Aplicação de linha de comandos para gerir campanhas de marketing. Tem três
perfis de utilizador:

* **Administrador** — gere clientes, marketeers, campanhas e budgets;
* **Marketeer** — cria e acompanha os criativos das campanhas que lhe estão
  atribuídas;
* **Cliente** — pede campanhas, acompanha o trabalho e aprova os criativos.

Esta documentação descreve como instalar e configurar a aplicação, como está
organizado o código e o que faz cada módulo.
